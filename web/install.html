Сначала запустите Start-EKT.cmd на этом компьютере. Расширение подключится к локальному серверу автоматически — без ключей API и изменения настроек.

↓ Скачать расширение EKT Assistant (.zip)

  1. Распакуйте скачанный архив в отдельную папку.
  2. Откройте chrome://extensions и включите «Режим разработчика».
  3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
  4. Откройте или обновите ekt.kz и нажмите «Спросить ассистента».

Если установлена старая версия, удалите её перед установкой новой. Сервер должен оставаться запущенным на том же компьютере, где работает Chrome.

После подтверждения появится alert, имитирующий добавление товара на сайте. Расширение не оформляет заказы и не принимает оплату.
