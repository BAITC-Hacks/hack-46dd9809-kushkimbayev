# Дизайн ИИ-консультанта EKT Интерактивный макет для кейса HACKALEM AI / ТОО «Электрокомплект». Визуальный стиль основан на ekt.kz: синие элементы, белые карточки, оранжевое выделение кнопок и рамок при наведении. **Это дизайн-макет.** Данные товара и ответы — примеры; ИИ и API не подключены, реальная корзина сайта не изменяется. Для установки расширения сервер и пароли не нужны. ## Посмотреть прямо на ekt.kz 1. Скачайте репозиторий либо распакуйте `ekt-design-extension.zip`. 2. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge). 3. Включите режим разработчика → **«Загрузить распакованное расширение»**. 4. Выберите **`дизайн/extension`** или папку распакованного архива, в которой находится `manifest.json`. 5. Откройте / обновите https://ekt.kz и нажмите **«Консультант EKT»** внизу справа. Если уже установлено другое расширение EKT, временно выключите его, чтобы кнопки не накладывались. После изменения файлов обновите расширение и вкладку сайта. ## Что можно проверить - Кнопка консультанта закреплена внизу справа. - Перемещение окна за синюю верхнюю панель. - Изменение ширины и высоты за угол **◢ справа внизу**. - Кнопки **«Развернуть»** и **«Восстановить»**; окно остаётся в пределах экрана. - Карточка с фото из каталога партнёра, артикулом, характеристиками и примером цены. - Плавное открытие / закрытие, переход кнопок из синего в оранжевый, подсветка карточки. - Демонстрация добавления только после отдельного подтверждения. - Состояния для клавиатурного фокуса и поддержка настройки уменьшения движения. Нажатие значка расширения открывает то же окно на странице ekt.kz, а не ограниченный браузерный popup. Если вкладка ещё не обновлена или открыт другой сайт, появится инструкция. ## Посмотреть локально, без установки расширения Из корня репозитория (Node.js 22+): ```sh node дизайн/preview-server.mjs ``` Откройте http://127.0.0.1:8788. Это отдельная тестовая страница с тем же окном, кнопкой и перетаскиванием. Если порт занят, завершите ранее запущенное превью. Окно терминала должно оставаться открытым. ## Файлы для команды | Файл / папка | Назначение | | --- | --- | | `extension/` | Последний дизайн v0.4.0, готовый к установке | | `extension/app.html`, `app.css`, `app.js` | Интерфейс и сценарии макета | | `extension/content.js` | Кнопка, перемещение, изменение размера и анимация окна | | `extension/background.js` | Открытие окна по значку расширения | | `extension/assets/` | Фото товара и ссылка на источник | | `ekt-design-extension.zip` | Архив той же версии расширения | | `preview.html`, `preview-server.mjs` | Локальное превью | | `design-directions.html` | Первоначальные три дизайн-концепции; открывается двойным нажатием | В текущем макете показан один фиксированный пример — провод СИП-4. Макет не определяет товар открытой страницы. История, положение окна и демонстрационное добавление сбрасываются при перезагрузке. Фото включено локально; другие внешние зависимости для расширения не нужны. Проверены в локальном браузере: открытие, наведение, подтверждение, сворачивание, перемещение мышью, растягивание окна, разворачивание и восстановление размера. Установка и работа в конкретном Chrome/Edge требуют загрузки расширения пользователем.
